🔐 Zero-Leak Order Tracker · User Guide

👨‍💼 For Factory (Workshop Supervisor)

Receive QR Code: Generated by the sales rep, printed on the production traveler.

Scan with WeChat: No app download, no registration required.

Update Progress: Select the current stage (e.g., Sewing), drag the slider to set the completion percentage (e.g., 60%).

Upload Photo (Optional): Take a live photo of the workshop to sync to the buyer's dashboard.

Sync: Click the button, and the buyer's overseas dashboard will update instantly.

🌍 For Buyer (Overseas Client)

Click Your Unique Link: No registration, direct access.

View Real-Time Progress: See the current production stage and completion percentage.

View Live Photos: Workshop photos with anti-counterfeit watermarks for authenticity.

Secure Isolation: You can only see your own order, with no access to other clients' data.

🛡️ Core Guarantees

Buyer Identity Masked: Factory side only shows Overseas Client (ID: #X99).

Dynamic Watermark: The buyer's dashboard and photos are watermarked with their company name; leaks are traceable.

One Token per Order: Each order has an independent encrypted token, ensuring absolute data isolation.
